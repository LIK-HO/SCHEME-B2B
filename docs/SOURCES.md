# Источники и проверка

ФНС описывает интеграционный доступ к ЕГРЮЛ/ЕГРИП как файловые выгрузки. На 2026 год действуют новые форматы ЕГРЮЛ 4.08 и ЕГРИП 4.07; переходный период старых форматов продлён до 22.01.2027.

В SCHEME-B2B:
- FNS_RSMP_PATH — локальная XML/ZIP выгрузка для источника кандидатов.
- FNS_EGRUL_BULK_PATH — локальная XML/ZIP выгрузка ЕГРЮЛ/ЕГРИП для фактической проверки.
- ROSSTAT_REGISTRY_PATH — локальный CSV статистического регистра.

Worker не скачивает большие государственные дампы на каждом запуске. Обновление файла выполняется отдельным контролируемым процессом, после чего core читает локальный snapshot.

Приоритет:
1. ЕГРЮЛ/ЕГРИП — идентичность и реквизиты.
2. Реестр МСП — сегментация и покрытие.
3. Статистический регистр Росстата — классификация/идентификация.
4. ОКВЭД и ОК ТЭИ — справочная классификация.

ОКВЭД не является доказательством фактической деятельности компании. В открытом доступе не публикуются процентные доли видов деятельности.

Не используется scraping внутреннего web-интерфейса ЕГРЮЛ или неофициальные reverse-engineered API. Это сознательное ограничение ради стабильности.

При отсутствии официального snapshot система не объявляет реквизиты подтверждёнными и фиксирует ошибку.

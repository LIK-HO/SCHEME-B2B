# FNS verification contract

ФНС предоставляет открытые и общедоступные сведения ЕГРЮЛ/ЕГРИП и отдельные режимы интеграции. Для интеграции больших файлов ФНС использует официальные форматы, в 2026 году актуальны новые версии форматов ЕГРЮЛ 4.08 и ЕГРИП 4.07, при этом переходный период для старых форматов продлён до 22.01.2027.

В SCHEME-B2B это разделено на два уровня:

1. Локальная формальная проверка контрольных сумм — всегда доступна и бесплатна.
2. Фактическая проверка существования и соответствия записи в ЕГРЮЛ/ЕГРИП — отдельный adapter.

Текущая конфигурация FNS_MODE=checksum не выдаёт формальную проверку за подтверждение ФНС.

Для production интеграции задаётся FNS_MODE=official и FNS_VERIFY_URL, который должен возвращать нормализованный JSON:

{
  "found": true,
  "inn": "7707083893",
  "ogrn": "1027700132195",
  "ogrnip": ""
}

Worker сравнивает ИНН и предоставленный ОГРН/ОГРНИП с ответом. Секрет не записывается в Airtable или Git.

Источник: официальный сервис ФНС по интеграции и доступу к данным ЕГРЮЛ/ЕГРИП.

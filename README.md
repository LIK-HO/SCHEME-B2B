# SCHEME-B2B

Минимальное ядро ручного B2B-поиска.

## Задача

**Найти компанию -> проверить ФНС -> убрать дубликаты -> понять потребность -> показать оператору.**

Операторская база и панель находятся в Airtable. Клиент и Архив — не отдельные копии компаний, а представления мастер-таблицы **Компания** по статусу.

В ядре нет расписаний, уведомлений, очередей, микросервисов и второй CRM.

## ФНС

Официальный контур ФНС ЕГРЮЛ/ЕГРИП предоставляет интеграцию в XML/ZIP-файлах с полными сведениями и ежедневными изменениями; доступ к FTP-интеграции ФНС предоставляется по атрибутам доступа и клиентскому сертификату.

Для бесплатного ручного режима используется официальный скачанный snapshot:

    python -m scheme_b2b import-fns /path/to/egrul.zip

После импорта:

    python -m scheme_b2b check 7707083893 1027700132195

Ядро проверяет ИНН, ОГРН/ОГРНИП, ищет актуальную запись по ИНН и возвращает статус, название и адрес. Ликвидированные/прекратившие деятельность записи не считаются действующими.

Телефон не выдаётся за «проверенный ФНС», если он не получен из соответствующего официального источника. Телефон и доказательство потребности идут от источника обнаружения.

## Проверенные принципы

- потоковый XML-парсинг;
- детерминированная проверка контрольных сумм;
- ключ записи ФНС: ОГРН/ОГРНИП;
- более новая выгрузка заменяет старую;
- один ИНН не должен повторяться в рабочей базе;
- отсутствие подтверждения не трактуется как подтверждение.

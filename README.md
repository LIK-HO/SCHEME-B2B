# SCHEME-B2B

Простой ручной B2B-поиск для Москвы.

## Назначение

Поиск -> проверка ФНС -> дедупликация -> доказательство потребности -> работа оператора.

Нет автоматического расписания, уведомлений, очередей, микросервисов или дублирующих таблиц компаний.

## Источник истины

ФНС используется для проверки юридической сущности, ИНН, ОГРН/ОГРНИП, адреса и статуса. Контактные данные и доказательство потребности берутся из источника, где найден кандидат. Система не называет телефон подтверждённым ФНС без соответствующего поля в официальном ответе.

## FNS

Официальная файловая интеграция ФНС использует XML/ZIP. Полные сведения и ежедневные изменения идентифицируются ОГРН/ОГРНИП; ФНС прямо описывает необходимость потоковой обработки файлов.

Для ручного бесплатного режима пользователь скачивает официальный snapshot и один раз импортирует его:

    python -m scheme_b2b import-fns /path/to/egrul.zip

После импорта поиск кандидата выполняется по локальному SQLite-индексу.

## Кандидаты

JSON:

    {
      "companies": [
        {
          "company": "ООО Ромашка",
          "inn": "7707083893",
          "ogrn": "1027700132195",
          "sphere": "Логистика",
          "need": "Переезд склада",
          "need_evidence": "Публичный запрос на складские работы",
          "need_source": "https://example.ru/source",
          "phone": "+7 999 123-45-67",
          "website": "https://example.ru",
          "source": "Отраслевой источник"
        }
      ]
    }

Запуск:

    python -m scheme_b2b import-candidates candidates.json

## Панель

    uvicorn scheme_b2b.app:app --host 0.0.0.0 --port 8080

Панель адаптирована под экран телефона.
